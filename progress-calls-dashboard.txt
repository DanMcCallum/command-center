## Learnings
(Patterns discovered during implementation; read before starting a story.)

- The Python note path returns an outbox receipt, not an ID task id; the id lands in `outbox.result` after the 5 s outbox loop. UI polls `GET /api/v1/outbox/{id}`.
- `scripts/run_receiver_dev.py` starts no background loops, so a replayed ringing never pops there. Use `scripts/run_e2e_dev.py` (US-008) for anything involving pops.
- The no-em-dash hook blocks writes that quote Python strings containing one (the note title format). Describe such strings instead of quoting them.
- uvicorn's access log (production runs `log_level="info"`) prints the full request line, query string included, so a `?token=` request writes the API token into the service log. The command-center client and SSE relay must send the token only as `Authorization: Bearer`; `?token=` exists for ad hoc EventSource debugging, not for anything that runs routinely.
- `build_service(..., calls_api_token=None)` falls back to `config.calls_api_token()`; tests pass `calls_api_token="t0k"` (or `""` to exercise fail-closed) to stay hermetic. `register_api(app, deps, token=...)` takes the same `DashboardDeps` object `register_dashboard` gets.
- SSE tests: wait for the first `: keepalive` line before publishing (it proves the subscription exists), with the app built at `sse_heartbeat=0.1`. `make_app(conn, token, sse_heartbeat=...)` and the `live_api` fixture in `tests/test_api_v1.py` are reusable for later API stream tests.
- Test fakes live in followupdominator `tests/fakes.py` (`FakeIDClient`, `FakeDialPadUsers`); tests import them as `from fakes import ...` (pytest prepends `tests/`, no `__init__.py`). A script outside `tests/` (the US-008 runner) must put `tests/` on `sys.path` first. `make_app(conn, token, id_client=..., lookup=...)` in `tests/test_api_v1.py` exposes the deps as `app.state.test_deps`; the `records_app` fixture there seeds property 5692, nickname "Test Meadow" (`test-meadow`) and an unresolved "Ghost Hollow".
- `TransientApiError` needs `service=` (`TransientApiError("timeout", service="id")`). API routes that read live ID map it to 502 `{error: "Investment Dominator did not respond"}`, which the command-center mapper forwards as-is.
- Ops badge thresholds live in one place: `ops_badges(summary)` in followupdominator `app/dashboard.py` returns `[{label, text, level}]`; the HTML strip renders from it and `GET /api/v1/ops` returns it, so the React strip colors by `level` and never re-derives thresholds. Labels are stable keys (`dead letters`, `outbox queue`, `event backlog`, `last sync`, `health: <key>`, `sync error`, `sync warning`); `text` is the display string.
- Write choke points shared by HTML and API live in followupdominator `app/dashboard.py`: `submit_note(deps, *, note, client_uuid, call_id, status, follow_up, caller, contact_id, property_id) -> NoteOutcome(receipt, call_id, client_uuid, fallback_close)` and `attribute_caller(lookup, *, slug, number, first_name, last_name) -> (contact_id, property_id)`. `fallback_close` is a key of `FALLBACK_CLOSE_MESSAGES` (`queued`, `not_delivered_yet`, `unreadable`) or None; the HTML route maps it to its old sentence.
- Keeping an existing Python string that contains an em dash while moving code: write the new block to a temp file with a placeholder and splice it with a small python script that substitutes `chr(0x2014)` (the hook only sees tool content). Done for the note title and the HTML note messages in US-006.
- `tests/fakes.py` has `FakeIDWriter(FakeIDClient)`: records `writes` as `(kind, payload)` tuples, `create_contact` appends a recoverable contact (next id after 7 is 8; `recoverable=False` forces the 409 path; `create_contact_error` raises), tasks get `t_id` 9001, 9002, ... The `writes_app` fixture in `tests/test_api_v1.py` wires it with lookup, agents and the Test Meadow nickname. The US-008 runner can subclass it to append JSON lines to the record log.
- `POST /api/v1/notes` on a duplicate `client_uuid` returns `enqueued: false` with the ORIGINAL `outbox_id` (looked up by event key), so the UI can keep polling `/api/v1/outbox/{id}` after a double submit.
- `ruff format --check` already flags `app/api_v1.py` (one pre-existing line from US-004), `app/db.py`, `app/service.py`, `tests/test_migrations.py`; the gate is `ruff check`, not format. Format only the files you touch.
- `docs/api-v1.md` in followupdominator is the contract for US-009 onward. Pop `summary` strings and task titles really contain an em dash, so the doc's examples cut them before it; client code must treat `summary` as opaque text. Typed query/path params (`start`, `limit`, ids) fail FastAPI validation with 422 `{detail: [...]}` BEFORE the token check; the PRD's mapper list (400, 404, 409, 502) does not mention 422, so the client should forward it like a 400 or just never send non-integers. `GET /api/v1/tasks` orders null `start_ts` first (SQLite). `GET /api/v1/ops` `health_flags` is an object `{key: value}`, not a list.
- To regenerate example payloads, a throwaway script that imports `make_app`, `request`, `bearer`, `API_TOKEN` from `tests/test_api_v1.py` (with `tests/` and the repo root on `sys.path`) and drives the routes over `httpx.ASGITransport` works from `/tmp`; run it with followupdominator as the cwd.
- Baselines 2026-10-12: pytest 265 passed, ruff clean; `npx tsc --noEmit` clean; `npm test` 48/50 with the two known `ebay-html.test.ts` failures.
