# Voice corpus

Cleaned phone-call transcripts that prime Claude on your speaking voice. Ads generated by the Ad Builder are written to sound like you — cadence, word choice, sentence rhythm — without quoting any specific call.

## `raw/`

Drop original transcripts here. Any plain-text format is fine (`.txt`, `.md`). Dialpad's exported call transcripts work directly — no preprocessing required.

## `clean/`

Output of the `clean-voice` workflow. Each file in `raw/` produces one matching file in `clean/` with:

- filler words removed (um, uh, like, you know)
- false starts and self-corrections collapsed to the corrected version
- nervous repetition removed
- PII scrubbed (names, phone numbers, addresses unless they're property addresses you want preserved)
- speaker labels preserved if present
- your sentence structure, idioms, and word choices kept intact

To run: create a task with `slashCommand: clean-voice` (or trigger it manually). It picks up any file in `raw/` that doesn't yet have a clean counterpart and writes one.

## Privacy

Phone-call transcripts contain personal information about real customers. The `clean/` step removes obvious PII, but review the output before you trust it. Files in this folder are never shipped anywhere — they only get read at ad-generation time on this machine.

If you accidentally drop a transcript with sensitive details (medical, financial, legal advice), delete both the raw and clean versions immediately.
