## Design decisions

- **Placement**: prepended to the tasks page (above "Tasks" header and form), not a separate route. The operator lands on `/tasks` and sees Roadmap first.
- **Section is open by default** on load; operator can collapse it.
- **Items are collapsed by default**; operator clicks title row to expand and read the full body.
- **Body rendering**: `whitespace-pre-wrap font-sans` — same pattern as TaskCard descriptions. No markdown library introduced.
- **Write support**: not implemented (out of scope per task). Seeding is done by editing `todos.json` directly.
