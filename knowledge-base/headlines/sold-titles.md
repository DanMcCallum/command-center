# Sold-ad headlines (proven copy)

Each line below is a real headline that was used to sell a property. Use this corpus to pattern-match headline craft: cadence, clause ordering, density of concrete anchors, and how value is signaled. Do not copy phrasing verbatim.

## What to extract

- **Lead with the buyable thing**: acreage + location (with state abbreviation), or lot type + location.
- **Stack concrete value anchors**: county assessed value, sold comps in area, nearby listing prices. These do more work than adjectives.
- **End with the offer**: explicit price, often paired with a financing option ("$X with $Y Down or $Z Cash").
- **Use property-specific qualifiers**: "Allows Mobile Homes," "Off the Grid," "Legal Access," "No HOA," "Unrestricted." These are buyer-filter signals, not fluff.

## What NOT to copy

- **Em dashes.** Every title here uses them as clause separators. The current writing rules (`skills/anti-slop.md`) forbid em dashes. Replace with periods or commas when borrowing structure.
- **Stacked exclamation marks ("!!", "BUY TODAY FOR $X!!").** These were on-brand for the older listings. Use sparingly or not at all in new copy unless the platform's buyer profile calls for it.
- **ALL-CAPS calls-to-action** unless the platform's buyer profile rewards them.
