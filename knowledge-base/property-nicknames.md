# Property nicknames — call-attribution registry

Every ad description ends with a short `(Property: <Nickname>)` tag (see `generate-ad.md` step 2b and the "Then write the description" section). The nickname has no selling purpose — it exists purely so a caller who saw the ad, or a lead who was told it on an outbound call, has a short memorable phrase to say on the phone so the call can be attributed to the right property before a phone number is on file. See `~/claude/followupdominator/design_patterns.md` section 5b for the full design this feeds.

This file is the uniqueness registry for nicknames generated by `generate-ad.md`, and doubles as the source data followupdominator's `property_nicknames` table will import from once it's built (Phase 3 there, not yet started as of 2026-07-03).

## Rules

- One nickname per property, for the life of the listing. Never regenerate a nickname for a slug that already has one here — reuse it.
- Two words: a descriptive adjective/terrain word + a location/terrain-flavored noun (e.g. "Whispering Pines", "Cedar Ridge", "Silver Hollow"). Grounded in something true about the property from its metadata — never invent a feature.
- Must be unique (case-insensitive) across every entry below.
